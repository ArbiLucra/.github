# ArbiLucra

Documentação pública e orientações de colaboração da ArbiLucra, uma iniciativa em desenvolvimento para apoiar a análise de oportunidades de arbitragem entre corretoras de criptoativos e a compreensão dos custos e riscos envolvidos.

Esta etapa estabelece a base documental. Não há produto público disponível ou resultados de rentabilidade demonstrados por este repositório.

- [Apresentação da organização](profile/README.md).
- [Como contribuir](CONTRIBUTING.md).
- [Cuidados com relatos de segurança](SECURITY.md).
- [Instruções para agentes neste repositório](AGENTS.md).

Os templates de issues e pull requests ajudam a descrever mudanças e suas verificações. A existência desses arquivos não comprova checks automáticos, proteção de branches ou um processo de revisão configurado.

Os templates de issues ficam em `.github/ISSUE_TEMPLATE/` dentro deste repositório, conforme a [documentação oficial de arquivos de colaboração padrão](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file). A ativação no GitHub depende de publicação posterior; esta entrega é local.
